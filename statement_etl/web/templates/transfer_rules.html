● Connected to YNAB

A rule is one direction: money going from Bank #1 to Bank #2, with the text each bank's statement shows for it, e.g. from GCash ("Transfer to 0917123") to GoTyme ("InstaPay from GCash"). Capital letters and extra spaces don't matter.

Money going the other way shows different text, e.g. GCash's "Received GCash from …", so it needs its own rule with the banks swapped.

Import either statement first: it makes the transfer in YNAB, and the other one finds it there and doesn't add it again. Leave Bank #2's text empty if you only import Bank #1's statements.
