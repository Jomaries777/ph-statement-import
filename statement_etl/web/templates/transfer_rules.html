Rules

In statements from the source bank, a row whose description contains the text is a transfer to the destination bank. Capital letters and extra spaces don't matter.

Add a rule for each side, e.g. in GCash statements "Transfer to 0917123" goes to GoTyme, and in GoTyme statements "InstaPay from GCash" goes to GCash. Whichever statement you import first makes the transfer in YNAB; the second one finds it there and doesn't add it again.
